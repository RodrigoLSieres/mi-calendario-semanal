# Mi Jornada

Aplicación web progresiva preparada para GitHub y Vercel.

## Publicación

1. Sube todos los archivos de esta carpeta a la raíz de un repositorio de GitHub.
2. En Vercel, selecciona **Add New > Project** e importa ese repositorio.
3. Deja **Framework Preset** en **Other** y no añadas comandos de compilación.
4. Pulsa **Deploy**.
5. Abre la dirección publicada desde el móvil y usa **Añadir a pantalla de inicio** o **Instalar aplicación**.

## Datos

Los registros se guardan en el almacenamiento local del navegador del dispositivo. No borres los datos del sitio si quieres conservarlos.
